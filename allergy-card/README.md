# 緊急アレルギー情報カード (GitHub Pages版・サーバー不要)

入力した情報を **URLの「#」以降** に圧縮して埋め込み、そのURLをNFCタグに書き込む方式です。
サーバーもデータベースも使いません。

## なぜ個人情報がGitHubに残らないのか

- 情報はタグに書き込むURLの `#` 以降にだけ入ります。`#` 以降はブラウザの中だけで処理され、
  サーバー(GitHub)には送信されません。
- このリポジトリに入っているのは「画面を作るコード」だけで、誰の情報も含みません。
  公開リポジトリにしても問題ありません。
- ページは外部通信を一切しません(CSPで `connect-src 'none'`)。

## 公開手順(GitHub Pages)

1. GitHubで新しいリポジトリを作る(例: `allergy-card`)。
2. このフォルダの中身(`index.html` `app.js` `codec.js` `style.css` `.nojekyll`)をアップロードする。
3. リポジトリの **Settings → Pages → Build and deployment** で
   `Deploy from a branch` / `main` / `/ (root)` を選んで保存する。
4. 数分後に `https://ユーザー名.github.io/allergy-card/` で開けるようになる。

## 使い方

1. 公開したページを開き、情報を入力する。下に **NFCタグに書き込むURL** が自動で作られる。
2. 「タグの種類」を選ぶと、容量メーターが実際のタグに合わせて動く。
3. Android版Chromeなら「NFCタグに書き込む」ボタンで直接書き込める(未検証機能)。
   それ以外は「URLをコピー」して NFC Tools などのアプリで書き込む。
4. 書き込んだら、別のスマホでかざして表示を確認する。
5. 確認できたら、必要に応じてタグをロック(読み取り専用化)する。

内容を変えたいときは、タグをかざして開いたページの右上「編集する」から直し、
新しいURLをタグに書き直す(ロック済みのタグは書き直せません)。

## 容量の目安

| タグ | NDEFの実質容量 |
|---|---|
| NTAG213 | 約137バイト |
| NTAG215 | 約492バイト(504バイト品) |
| NTAG216 | 約868バイト |

- 圧縮が効きにくい日本語の文章は、ほぼ「1文字=約3バイト」で効いてきます。
- アレルゲン名は、入力欄の候補(卵・乳・小麦…28品目)から選ぶと、1項目あたり数バイトで済みます。
- 容量メーターが赤くなったら、メモを短くするか項目を減らしてください。
- メーターは「`https://` が1バイトに圧縮される」前提の見積もりです。アプリによってはこの圧縮をしないため、
  余裕が少ないときは入らない場合があります。

## 注意(この方式の限界とセキュリティ)

- **URLそのものが情報です。** SNS・メール・GitHubのIssueやREADMEなどに貼らないでください。
  スマホのブラウザ履歴にも残ります。
- **タグを読み取れる人は誰でも内容が見えます。** 載せる情報は最小限に(続柄、住所は載せない等)。
- **更新にはタグの書き直しが必要です。** ロックすると改ざんは防げますが、書き直せなくなります。
- **偽タグへのすり替え**は、ソフトでは防げません。改ざん検知シールの併用を推奨します。
- GitHub Pagesはレスポンスヘッダーを設定できないため、CSPは `<meta>` で指定しています。
- 定義済みアレルゲンの一覧(`codec.js` の `PRESETS`)は **末尾に足すだけ** にしてください。
  並べ替え・削除をすると、すでに書き込んだタグの表示が壊れます。

## ファイル構成

```
index.html   画面(閲覧・入力・URL生成)
app.js       画面の動き
codec.js     データ ⇔ URLの変換(圧縮)
style.css    見た目
.nojekyll    GitHub Pagesでそのまま配信するための空ファイル
```
